# Inline function
## If a function doesn't add useful meaning or abstraction, replace the function call with its body and remove the function.
### But there's an important caveat. A small function, in and of itself, isn't a reason to create an inline function.
### There's no need to inline a function when it provides a meaningful name, hides the details, or represents a distinct concept.
